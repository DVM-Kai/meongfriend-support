Review Context

Recorded on an actual Samsung SM-A505N running Android 11 and TripRibbon 0.1.14 (15). The device uses the development-signed build to preserve existing installation data; its location-service source is the same as the uploaded release bundle. This is not a capture of a Play-delivered installation.

  • Explicit recording consent, end time and recipient controls.
  • Android location permission and user-started native foreground recording.
  • An ongoing Android notification while the app is not in the foreground.
  • Stopping from the app. Notification-stop behavior was also tested separately.

This video deliberately uses a disposable local-only trip. No account login, server upload or live companion-sharing session is shown. Precise location areas and unrelated device notifications are masked. Clips are joined at normal speed to remove waiting time; app behavior is not simulated.

시연 범위

실제 안드로이드 휴대폰에서 동의·종료 시간 설정, 위치 권한, 지속 알림, 앱의 기록 중지를 촬영했습니다. 기존 설치 데이터를 보존하기 위해 개발용 서명의 동일 버전으로 촬영했으며 Play 설치본 촬영은 아닙니다. 서버 전송이 없는 별도 테스트 여행을 사용했고 실제 좌표와 다른 앱 알림은 가렸습니다. 서버 공동 편집·동행자 위치 수신이나 자동 시간 만료를 시연했다고 주장하지 않습니다.
